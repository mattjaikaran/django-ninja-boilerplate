{# ── Agent sync loop ───────────────────────────────────────── #}

How agents keep this in sync

  • The format and the sync rules live in docs/product/README.md.
  • Agents load the journey-sync skill (.agents/skills/journey-sync/SKILL.md) when they change a feature, a journey, or a Playwright test.
  • Write one Playwright test per journey in the frontend, tagged @J-001, with steps titled test.step('J-001-S1: ...'). A step is verified only by a passing step in the JSON report.
  • Check a feature [x] or set a journey done only when every step is verified.
  • Run uv run python scripts/check_journeys.py. Errors fail the JOURNEYS gate.
{# ── Adoption ────────────────────────────────────────────────── #}

Reuse this page in another backend

Run these from a checkout that contains this app, next to the other backend. The script copies the files, refuses to overwrite your changes, and prints the wiring. The guide is docs/ADOPTING_UPDATES.md.

  • uv run python scripts/adopt.py list
  • uv run python scripts/adopt.py status --target ../my-api
  • uv run python scripts/adopt.py apply journeys --target ../my-api
