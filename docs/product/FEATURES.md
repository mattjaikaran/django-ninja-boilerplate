# Features

This file lists the product features of the boilerplate, grouped by area.
A checked box `[x]` means "verified by a passing Playwright journey". It
never means "the code exists". See [README.md](README.md) for the rules.

Every feature is unchecked here: this repository has no Playwright suite.
The frontend that adopts this backend checks features off as its tagged
journey tests pass.
